Experiment-system evaluation

Multivariate assignment, event integrity, and inference calibration.

VariantGrid treats an experiment as a versioned decision contract. It combines typed multivariate design, deterministic assignment, event-integrity gates, calibrated inference, and an operator workflow that withholds conclusions when the evidence is compromised.

Decision path

Each stage leaves evidence for the next one. A failed integrity check interrupts the path before an effect estimate can become a recommendation.

1. DefineHypothesis, metrics, states, constraints
2. FreezeImmutable version and allocation policy
3. ObserveAssignment, exposure, outcome events
4. GateSRM, integrity, timing, guardrails
5. DecideEffect, uncertainty, frozen record

Scope and reproduction

PYTHONPATH=src python3 scripts/verify_release.py

This command stages a clean copy and runs the test, benchmark, and adversarial-integrity suites. The resulting artifacts establish deterministic local assignment, calibrated seeded simulation, adversarial SQLite event handling, and a reproducible operator workflow. They do not establish distributed durability, production uptime, customer adoption, or causal business impact.
